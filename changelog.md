# Changelog

## [v0.5] - 2026-05-10

- Receiving multiboot2 info from GRUB
    - <small>`shiro_main(magic, mbi)` now picks up the EAX/EBX values that `boot.asm` already pushed</small>
    - <small>New `System::Multiboot` class parses the tag chain (memory map, basic meminfo, command line, framebuffer)</small>
    - <small>Memory size, available memory total, cmdline, and framebuffer dimensions are logged at boot</small>
- Remapping the legacy 8259A PIC pair
    - <small>Master moved to vector 0x20, slave to 0x28 — no more collision with CPU exceptions 0x08-0x0F</small>
    - <small>New `System::PIC` class with `Remap`, `Start`, `Unmask`, `Mask`, `EndOfInterrupt`</small>
    - <small>Drivers (timer, keyboard) now unmask their own IRQ line via `PIC::Unmask`</small>
- Adding IDT entries 32-47 for hardware IRQs
    - <small>Sixteen new asm stubs (`isr32`...`isr47`) generated by the existing `ISR_NOERRCODE` macro</small>
    - <small>`ISR::Handler` now dispatches by vector range: 0-31 → panic, 32-47 → IRQ + EOI</small>
- Implementing a programmable interval timer
    - <small>New `System::Drivers::Timer` class programs PIT channel 0 at 100 Hz (10 ms tick)</small>
    - <small>`Timer::ticks` available globally, `Timer::Sleep(ms)` blocks via `hlt`</small>
    - <small>Kernel main loop now sleeps with `hlt` between shell updates (no more spin)</small>
- Implementing a kernel panic handler
    - <small>New `System::Panic` class — every CPU exception (vec 0-31) now lands here</small>
    - <small>Repaints the screen white-on-red, dumps register state to VGA + serial, halts forever</small>
    - <small>Replaces the previous "EOI and return" silent ignore</small>
- Implementing a built-in shell command parser
    - <small>New `Shell::Execute(cmd)` dispatcher with: `help`, `clear`, `ver`, `uptime`, `echo`, `reboot`</small>
    - <small>`reboot` issues an 8042 keyboard-controller reset (`outb 0x64, 0xFE`)</small>
    - <small>Typed commands now appear in the scrollback prefixed with `Shiro> `</small>
- Boot flow tightened
    - <small>Order in `Shiro::Start`: GDT → PIC → IDT → Timer → Keyboard → TextMode → VGA → STI</small>
    - <small>Interrupts only enabled at the very end, after every subsystem is ready</small>
    - <small>Removed the redundant `Keyboard::Start()` call in `Shell::Start` (already done by `Shiro::Start`)</small>
- Misc
    - <small>`registers_t` extracted into `libs/registers.h` (was inline in `isr.class.h`)</small>
    - <small>New `libs/multiboot2.h` with multiboot2 spec structs</small>
    - <small>`strcmp` added to `libs/string.h`</small>
    - <small>`GDT::Start` and `IDT::Start` now log when they finish (helps triage triple-faults)</small>
- Implementing a real kernel heap (replaces broken bump allocator)
    - <small>New `System::Heap` class — first-fit free-list allocator with forward + backward coalescing on `Free`</small>
    - <small>4 MiB heap region placed immediately after the kernel image (linker now exposes `_kernel_start` / `_kernel_end`)</small>
    - <small>`operator new` / `operator new[]` now route through `Heap::Alloc`; matching `delete` / `delete[]` are real no-ops no more</small>
    - <small>Block headers carry a magic number `0x5481B07E` to detect double-free / bad-pointer-free</small>
- Implementing a Physical Memory Manager
    - <small>New `System::PMM` class — bitmap with one bit per 4 KiB page (1 Mbit, sized for 4 GiB tracking)</small>
    - <small>Boot-time scan of the multiboot2 memory map: marks `MB2_MEMORY_AVAILABLE` regions free</small>
    - <small>Re-reserves the kernel + heap range and the first MiB (BIOS/IVT/VGA)</small>
    - <small>`PMM::AllocPage` (linear scan, skips fully-allocated bytes), `PMM::FreePage`, `TotalPages/UsedPages/FreePages`</small>
- Implementing paging / MMU
    - <small>New `System::Paging` class — identity map of all 4 GiB using PSE 4 MiB pages</small>
    - <small>Single 4 KiB-aligned page directory in BSS; 1024 entries flagged P|RW|PS</small>
    - <small>Sets `CR4.PSE`, loads `CR3`, then sets `CR0.PG` — MMU live before `sti`</small>
    - <small>Page-fault exception (vector 14) now reaches `System::Panic` if anything misroutes</small>
- Implementing cooperative kernel multitasking with real context switching
    - <small>New `System::Scheduler` class — round-robin task table (8 slots), `READY` / `SLEEPING` states</small>
    - <small>New `boot/asm/switch.asm` — naked `switch_task(old_esp, new_esp)` that saves ebp/ebx/esi/edi, swaps ESP, restores</small>
    - <small>`Spawn(fn, name)` allocates a 4 KiB stack from the heap and pre-formats it so the first switch lands at the entry function</small>
    - <small>`Yield()` and `Sleep(ms)` cede the CPU; sleeping tasks wake when their tick deadline passes</small>
    - <small>Demo background tasks: `task_spinner` animates `|/-\` and `task_heartbeat` blinks ♥ in the header bar</small>
    - <small>Main kernel loop now `Yield`s every iteration before `hlt`</small>
- Expanding the built-in shell into a real command dispatcher
    - <small>New `Applications::Commands` class — table-driven dispatcher with 14 builtins</small>
    - <small>New commands: `mem`, `pmm`, `paging`, `tasks`, `ticks`, `date`, `cpuid`, `halt`, `panic`</small>
    - <small>Existing commands (`help`, `ver`, `uptime`, `clear`, `echo`, `reboot`) preserved and reworked through the same dispatcher</small>
    - <small>`Shell::Execute` is now a thin wrapper around `Commands::Dispatch`</small>
- Linker script hardening
    - <small>`.grub` listed first AND `.text` listed explicitly so GCC's per-function `.text.*` sections don't push the multiboot2 header past the 32 KiB scan window</small>
    - <small>Globbed-in patterns (`*(.text.*)`, `*(.rodata.*)`, etc.) so future modules don't leak into the wrong section</small>
- Implementing an in-memory filesystem (initrd)
    - <small>New `tools/mkinitrd.py` packs `src/initrd/*` into a baby-tar binary (magic `'SHIR'` + index + data)</small>
    - <small>GRUB loads it as a multiboot2 module via `module2 /boot/initrd "shiro-initrd"`</small>
    - <small>New `System::Initrd` class — finds the `MB2_TAG_MODULE` tag, validates magic, exposes `Find(name)` / `Data(entry)`</small>
    - <small>New shell builtins: `ls`, `cat <filename>`</small>
    - <small>Initial files: `motd.txt`, `readme.txt`, `hello.txt`, `init.sh`</small>
- Implementing a boot-time init script (`init.sh`)
    - <small>kernel.cpp scans the ramdisk for `init.sh` after the shell starts and feeds each non-comment line through `Commands::Dispatch`</small>
    - <small>The default script runs `clear`, `cat motd.txt`, and an `echo` so the user sees a welcome screen without typing anything</small>
- Polishing the kernel panic screen
    - <small>Now reads `CR2` (faulting linear address) and decodes the page-fault `err_code` bits (P/WR/US)</small>
    - <small>All 8 GP registers + EIP / EFLAGS / ERR rendered in hex in two columns</small>
    - <small>Top-of-stack snapshot: 8 dwords starting at `regs.esp` for backtrace work</small>
- Adding memory-inspection commands
    - <small>`peek <hex-addr>` — reads a 32-bit value at the given address (forced 4-byte aligned)</small>
    - <small>`dumpmem <hex-addr>` — canonical hex+ASCII hexdump of 64 bytes</small>
    - <small>Both go through a shared `ParseHex` helper that accepts `0xABC` or `ABC`</small>
- Promoting the scheduler to preemptive
    - <small>`System::Drivers::Timer` now exposes `RegisterPreemptCallback(fn)`; the callback fires every 5 ticks (~50 ms)</small>
    - <small>`Scheduler::Start` registers `Scheduler::PreemptiveYield` with the timer, opting in</small>
    - <small>Yielding from inside the timer ISR works because switch_task pushes its callee-saved frame on top of the existing IRQ frame; on return, the original task's full state (including IRET frame) unwinds normally</small>
    - <small>`PreemptiveYield` re-entrance guard prevents two timer ticks landing nested mid-switch</small>
- Fixing a heap+initrd address collision
    - <small>GRUB drops the initrd module right after the kernel BSS, exactly where `_kernel_end` points</small>
    - <small>`Heap::Start` now takes a `base_hint`; kernel.cpp pre-walks the multiboot tags to find any module's end address and bumps the heap past it</small>
    - <small>Heap base is also 4 KiB-aligned now (was 16-byte) to keep things on page boundaries</small>
- Repainting the TUI in chat-style with status bar + tabs + boxes
    - <small>Layout reorganised — row 0 = header, row 1 = status bar, rows 2-23 = scrollback, row 24 = prompt</small>
    - <small>Header repainted with title left, tab strip ([1 term] [2 term] ... [5 dbg]) middle, animated heart/spinner/clock cluster on the right</small>
    - <small>New colour palette: white-on-blue header, black-on-white active tab, light-grey-on-blue inactive tabs, black-on-grey status bar, light-green prompt, yellow command echo</small>
    - <small>New `terminal_screen_status[160]` buffer + `RenderStatus(text)` / `WriteSAt(text, x)` helpers; UpdateScreen blits all four rows (header / status / content / footer)</small>
    - <small>`Scroll()` now derives content rows from absolute layout (`content_starting_point` / `footer_starting_point`) instead of hard-coded line numbers</small>
    - <small>`WriteCEcho` writes to the scrollback in the echo (yellow) colour; `Update()` uses it to echo the typed command in chat-style</small>
    - <small>`task_clock` paints HH:MM:SS uptime at columns 70-77 of the header; `task_statusbar` repaints row 1 every 250 ms with live heap/pmm/tasks/ticks</small>
    - <small>`RenderHeader` no longer fires from UpdateScreen — it's called only when the active terminal changes, so the animation cluster (cols 64-79) doesn't get clobbered</small>
    - <small>New `Commands::BoxTop` / `BoxLine` / `BoxBottom` helpers using CP437 ┌─┐│└─┘; `tasks`, `mem`, `pmm`, `paging` reformatted into framed output</small>
    - <small>`tasks` highlights the currently-running task with `>>` prefix</small>
- Modernising the build pipeline
    - <small>`Dockerfile` rewritten as a 2-stage `debian:bookworm-slim` build — stage 1 cross-compiles binutils 2.42 + gcc 13.2.0 + gdb 14.2 from source into `/opt/cross`, stage 2 is a slim runtime image with the toolchain `COPY`d in</small>
    - <small>Runtime image now ships `qemu-system-x86`, `novnc`, `websockify` so the OS can be booted entirely inside the container and viewed in a browser</small>
    - <small>Removed `install/` directory (`i686-elf-tools.sh`, `install.sh`, `network.sh`) — host-side installs are no longer needed</small>
    - <small>`docker-compose.yml` simplified — single `./src` bind mount, removed the external network and stale extra mounts</small>
    - <small>`make run` now boots QEMU detached inside the container with `-vnc :0` + websockify on `:6080`; user opens `http://localhost:6080/vnc.html` instead of installing QEMU on the host</small>
    - <small>New `make` targets: `docker-up`, `docker-down`, `docker-enter`, `run-host` (host QEMU), `stop-vm`, `gdb` (boots paused with `-S -gdb tcp::1234`), `clean`</small>
    - <small>New `.gitattributes` enforces LF line endings repo-wide; new `.dockerignore` keeps host `bin/`, `lib/`, `log/`, `grub/` build outputs out of the build context</small>
    - <small>`readme.md` rewritten around the docker-only workflow (Requirements / Build & Run sections updated, novnc URL documented)</small>

## [v0.4] - 2019-05-12

- Adding new methods and functions
- Improving ```Keyboard Driver```
    - <small>New ```Numeral Keys```</small>
    - <small>New ```Function Keys``` from ```F1``` to ```F5```</small>
- Implementing a new ```Applications``` namespace
- Implementing a Singleton Pattern for Shiro (kernel)
    - <small>The ```(auto &shiro)``` parameter is no longer required when calling a method</small>
    - <small>Now you can call ```System::Shiro::GetInstance()``` to access Shiro's methods</small>
- Implementing a Singleton Pattern for Shell (application)
    - <small>Now you can call ```Applications::Shell::GetInstance()``` to access the Shell's methods</small>
- Implementing a ```WatterMark Allocator``` for ```Memory Management```
    - <small>This is a very (very, very, ..., very) basic version of the feature</small>
- Implementing the ```new``` operator
- Implementing a Shell Switcher
    - <small>You can now change terminals by pressing ```F1``` to ```F5```</small>
    - <small>```F5``` is the ```Debug Terminal```</small>
    - <small>The current terminal is displayed at the top of the screen (header)</small>
- Removing ```VGA.Start()``` from inside ```Modes::Text.Start()```
    - <small>Now you can find it at ```Shiro.Start()```</small>
- Removing Shell from inside Shiro
    - <small>Now, instead of being part of Shiro, it can use Shiro's resources as an application.</small>
- Removing unused ```bios``` class from ```cursor``` class
